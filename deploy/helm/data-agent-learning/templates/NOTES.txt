This release deploys the OFFLINE plane only. The agent runtime, the agent UI and
the neo4j hydrator come from the sibling `data-agent` chart, and this plane reads
that release's data: the sweeper scans ITS Couchbase session bucket, and the
promotion scheduler replays against the warehouse as the SAME tenant. Confirm
COUCHBASE_*, NEO4J_*, EMBEDDING_*, MCP_URL and TENANT_* match the data-agent
release — a mismatch produces no error, only a loop that learns from nothing or
verifies against somebody else's rows.

The external backing services (ClickHouse, MCP, token IdP, OpenAI, Couchbase,
Neo4j, Redis, embedding API) are NOT deployed by this chart.

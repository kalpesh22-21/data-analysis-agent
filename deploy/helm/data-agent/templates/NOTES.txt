{{- if and (not .Values.secrets.existingSecret) (not .Values.secrets.data.MCP_SERVICE_KEY) }}

WARNING: the hydrator is enabled but MCP_SERVICE_KEY is EMPTY. The hydrator
authenticates the MCP export routes with a static service key (it has no user
JWT); with an empty key it REFUSES to start (blank creds would 401 every poll),
so neo4j is never seeded and every runtime pod fails its /ready gate FOREVER.
Set secrets.data.MCP_SERVICE_KEY (or provide MCP_SERVICE_KEY via existingSecret),
or disable the hydrator (components.hydrator.enabled=false).
{{- end }}

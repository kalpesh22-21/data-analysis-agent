# Lane5 loop report: implementation and validation

Branch: `feature/multi-capability-agent`; base: `0e0226b`.
The lab's divergence ledger is not in this checkout. This records the upstream
response; supplied external traces were not independently re-audited here.

- **RC1:** Duplicate-read nudges name the serving result and round. Synthetic
  discovery is round 0; legacy rounds are labelled unknown/prior window.
  Trimmed results are explicitly identified as unavailable. Markers contain no data.
- **RC2:** `MAX_READ_CALLS_PER_TOOL=3` limits actual read dispatches per tool name
  per budget window, regardless of arguments. Blueprint and knowledge searches
  now join read deduplication. The first blocked attempt coaches; later attempts
  decline with `READ_REFETCH_LIMIT` and `loop_read_refetch_limit` telemetry.
  Legitimate discovery needing more reads requires a higher configured limit.
- **RC3:** `MAX_NO_PROGRESS_ROUNDS=4` stops consecutive rounds without new
  successful evidence, after coaching on the preceding round. Status:
  `stopped_no_progress`; event: `loop_no_new_evidence_stop`. Pending intents are
  blocked and an honest limitation is persisted; existing shipping checks apply.
  Progress uses local result fingerprints, plus arguments for warehouse executions
  so distinct empty populations count. Errors, reused preparations and new IDs
  alone do not count as progress.
- **RC4:** `HELP_CENTER_FAILURE_LIMIT=2` disables Help Center tools for the rest
  of the turn after consecutive availability failures. The breaker survives
  resume, removes schemas and emits `loop_help_center_circuit_opened`.
- **RC5 ruling:** Keep original IDs unless empty or already used. Collisions get
  `original#1`, `original#2`, etc.; empty IDs use `call#1`. Reserve persisted,
  synthetic, assistant/tool and current-batch IDs. Preserve reasoning metadata
  and emit `loop_tool_call_id_reminted` with old/new IDs. Adopt one rename strategy,
  not one historical ID format: rewriting existing receipts would break references.
  Suffix lineage does not establish semantic equality between calls.
- **RC6:** Emit `loop_ask_user_batch_calls_dropped` with skipped names/IDs and
  round, visible in progress and Phoenix. This base already persisted honest
  `TOOL_NOT_EXECUTED` receipts; the change adds telemetry, not missing results.
